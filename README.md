# 成理校园 AI 管家（演示版）

> 本项目包含真实官方服务入口与百度网络搜索；账号、验证码、教室、座位、活动人数、食堂状态和办事记录均为演示数据，不连接校内预约系统、短信或付费 AI 接口。

## 官方服务与真实搜索

首页与服务大厅提供 12 项官方服务入口，按学习、生活、办事和成长分类。服务目录集中维护在 `lib/campus-services.ts`；需要登录的事项请在学校网站完成。

搜索支持站内服务、学校官网和全网三种范围。官网搜索通过百度限定 `cdut.edu.cn`，网络结果在新标签页打开；本站不伪造搜索结果，也不抓取校内账户数据。

## 统一源码与发布

本地与线上均渲染 `app/page.tsx` 和 `components/`，不再分别维护两套页面。

```bash
npm run dev
npm run build:pages
```

开发地址为 `http://127.0.0.1:4173/`。构建生成 `.pages-build/`，并把相同页面打包到 `github-pages/index.html`。原同步命令仍可使用，现改为执行统一构建。

公开源码与生成页面发布到 `cxk-676/cxk-676.github.io`。工作流 `.github/workflows/campus-pages.yml` 在主分支更新后构建、测试并发布到 Pages；发布结果以 GitHub Actions 运行记录为准。

## 本次交互完善

- 官方资料助手：证明申请、奖助学金、心理咨询、校历和图书馆校外访问，附官方来源与核对日期；采用关键词资料索引，不是大模型实时回答。
- 真实搜索：百度官网检索与全网搜索；本机保留最近八个关键词，可清空。
- 收藏：首页星标加入“我的”，刷新后保留。
- 月历：切换月份、选择日期筛选；演示活动与官方通知入口分开，人数与红黄绿进度条均标注为演示。
- 地图：官方地图本地图片、地点搜索、示意标记、放大、拖动和重置。标记不提供真实精确路线。
- 预约：已占用/本机已预约座位不可再选，重复预约有提示，“我的”支持取消。
- 失物：查询、详情、发布、编辑和删除本机信息；重置恢复原始示例。
- 手机：保留所有侧边栏目，可以收起侧栏。

## 快速启动

需要 Node.js 22 或更高版本：

```bash
npm install
npm run dev
```

首次访问会显示本机演示登录页。任意演示学号或手机号均可使用；密码登录只需输入非空密码，验证码登录会在页面生成本机验证码，不会发送短信。

运行校验：

```bash
npm test
npm run build:pages
```

展示网址：https://cxk-676.github.io/。无后台数据库，各浏览器演示记录互不共享。
